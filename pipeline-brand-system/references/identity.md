# Identity development

Create a decision ledger with `decision`, `value`, `evidence`, `status`, `rationale`, and `open_question`. Use statuses `source-derived`, `proposed`, `reviewed`, and `unresolved`; reviewed requires actual review evidence and is not implied by generation.

## Strategic and verbal identity

Write a compact brief: entity name and relationship to theme/run name; audience; problem; value proposition; differentiators supported by evidence; personality; communication goals; primary channels. Distinguish owner-provided facts from creative hypotheses. A language-themed artwork does not establish affiliation with a programming language's maintainers.

Define voice dimensions through usable rules. Include headline, explanatory paragraph, call to action, error message, and release/update examples. Provide an appropriate/avoid pair for each tone rule. Do not invent testimonials, market position, heritage, or legal claims.

## Visual identity

Inventory primary mark, wordmark, symbol, artwork, background textures, icons, and decorative diagrams as distinct roles. Identify which actually exist. A missing wordmark can be a proposed typographic lockup without becoming a newly approved logo.

For each usable mark document source, intrinsic dimensions/viewBox, transparent bounds, intended backgrounds, and known limitations. Define a clear-space unit based on measurable geometry; label it proposed and demonstrate it. Determine minimum size from rendered legibility tests; do not invent validated pixel minima. Show narrow/small use, dark surfaces, monochrome only if authorized and technically available, and prohibited stretching/cropping/effects. Mark absent variants as unavailable.

Derive a repeatable graphic language from actual artwork: motif, silhouette, geometry, line treatment, visual density, image framing and composition. Explain what transfers to UI versus editorial illustration. Avoid copying third-party trademark shapes into new assets or calling pipeline demo icons official brand symbols.

Define display/body/code typography roles, weights, size/line-height/letter-spacing, fallbacks, loading and script coverage. Inspect supplied fonts before adopting them; if choosing new fonts verify current official license and distribution terms. Record untested glyph coverage and fallback behavior. Do not bundle font files without supporting rights.

Supply a color usage hierarchy with canonical IDs, exact values, intended proportions as flexible guidance, supported surface/text pairs, and explicit prohibited uses. Keep brand primary distinct from status meaning when collisions occur.

For print requests, provide a separate production specification and flag profile/paper/proof dependencies. Do not present arithmetic RGB-to-CMYK conversion as a validated print match, invent spot-color matches, or let print proposals replace canonical RGB values.
