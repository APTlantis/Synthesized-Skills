Constraint classification: valid XML and coherent references are correctness requirements; standalone namespace applies to file delivery. Static self-contained output, readable geometry, transparent background, and explicit intrinsic dimensions are overridable defaults. Inline accessibility and ID prefixing are environment-specific. The starter's palette, shapes, dimensions, and stroke choices are example-only. User and project tokens take precedence over sample styling.

No material specification conflict was identified. Modern specification features and older target support are reconciled by target testing rather than promising universal compatibility. Specific screen-reader behavior, native editor imports, print color fidelity, advanced filter support, and animation are not certified by this package. Revalidate after target/tool changes or repeated failure. See the accompanying validation report for actual execution evidence.
